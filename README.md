# Cinema Website Project

## Overview
This is a multi-page responsive website created for a cinema project. The site allows users to browse movies, check ticket prices, view screening schedules, learn about cinema features, and book tickets online.

## Project Structure
The project consists of 5 pages:
1. **Home (`index.html`)**: Features trending movies and main cinema highlights.
2. **About (`about.html`)**: Provides details about the cinema experience and technology.
3. **Schedule (`schedule.html`)**: Displays movie times, screening halls, and ticket prices in a structured table.
4. **Movies (`movies.html`)**: Displays a full catalog of available movies with genre filter buttons.
5. **Contact (`contact.html`)**: Contains a booking and feedback form for visitors.

## Features & Requirements Implemented
- **Responsive Design**: Built using Media Queries (for mobile and tablet screens) and the Bootstrap Grid system.
- **HTML5 Semantics**: Structured using standard semantic elements (`header`, `nav`, `main`, `footer`, `section`, `table`, `form`).
- **CSS3 Styling**: Custom dark theme with consistent colors, Flexbox layout, hover effects, and custom UI components.
- **Form & Table**: Included a full interactive contact form and a responsive showtime pricing table.

## Technologies Used
